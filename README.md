# ЭкоЦикл — многостраничный интерактивный MVP

Прототип эко-соцсети и проводника в экономику замкнутого цикла для ECOHACK 2026.

## Как запустить

1. Скачайте папку `ecocycle`.
2. Откройте `index.html` в браузере — этого достаточно, сборка не нужна.
3. Для локального сервера (чтобы корректно работали все пути и `file://` не мешал):
   ```bash
   cd ecocycle
   python3 -m http.server 8080
