## 🌿 О проекте

**ЭкоЦикл** — это кроссплатформенная эко-соцсеть и проводник в экономику замкнутого цикла. Продукт решает три задачи одновременно:

- **Прозрачность.** Показывает человеку, куда на самом деле уезжает содержимое его контейнера — до конечного продукта, на данных реальных региональных операторов.
- **Вовлечение детей.** Превращает сортировку в игру через комиксы, симуляторы эко-заводов и школьные квесты.
- **Вторичное использование.** Помогает взрослым отдавать вещи соседям вместо свалки — с автоматическим расчётом спасённого CO₂.

Проект собран как **статический многостраничный MVP**: без сборщиков, зависимостей и бэкенда. Достаточно открыть `index.html` в браузере.

### Ключевые цифры

| Показатель | Значение | Комментарий |
|---|---:|---|
| Людей не сортируют отходы | **80%** | Не верят, что переработка реальна |
| Модулей в одном приложении | **4** | Живой путь, Джуниор, Шеринг, Сообщество |
| Снижение нагрузки на полигоны КГО | **15–20%** | За счёт C2C-шеринга в пилотных регионах |
| Возрастных групп вовлечено | **100%** | От школьников до взрослых |
| Страниц в прототипе | **9** | Полноценный многостраничник |
| Внешних зависимостей | **0** | Кроме Google Fonts |

## 🎯 Проблема и решение

### Проблема

| # | Проблема | Суть |
|---|---|---|
| 01 | Неверие и неизвестность | Путь отходов заканчивается у крышки контейнера — дальше пустота и сомнение |
| 02 | Слепая зона переработки | Нет связи между выброшенным предметом и его второй жизнью |
| 03 | Неэффективность утилизации | Пригодные вещи едут на полигон вместо повторного использования |

### Решение

| Ценность | Как реализована |
|---|---|
| **Прозрачность** | Визуализация полного пути каждой фракции до регионального оператора |
| **Вовлечение** | Геймификация эко-привычек для детей и школьников |
| **Вторичное использование** | Бесплатный C2C-шеринг вещей с расчётом спасённого CO₂ |

### Схема экосистемы

```text
 Дети и школьники                    Взрослые
(игра и привычки)              (шеринг и сортировка)
        \                                /
         \                              /
          ▼                            ▼
      ┌────────────────────────────────────┐
      │   Единая платформа «ЭкоЦикл»       │
      └─────────────────┬──────────────────┘
                        │
                        ▼
            Региональные операторы
            (данные о переработке)
```

### Вариант 1 — просто открыть файл


## 🧩 Модули продукта

### Модуль 01 · «Живой Путь Вещи»

> Трекер трансформации отходов с подгрузкой данных реальных заводов и операторов.

| Подгрузка данных операторов | 🔶 Демо-данные |
| Расчёт вторичного сырья | ✅ Показывается |
| Интеграция с реестром РЭО | 🔷 Запланировано |

> Игровые комиксы, симуляторы эко-заводов и квесты для детей.

## 📈 Метрики эффекта

| Метрика | Значение | Как считаем |
| --- | --- | --- |
| Снижение нагрузки на полигоны КГО | **15–20%** | По пилотным регионам за счёт C2C |
| Доверие к раздельному сбору | **рост** | Опросы до/после |
| Вовлечённость по месяцам | **+рост** | График в `impact.html` |
| Возрастных групп вовлечено | **100%** | От школьников до взрослых |
| Вещей спасено | **счётчик** | По сделкам в шеринге |
| CO₂ не выброшено | **счётчик** | По формуле на сделку |

### Формула CO₂ (демо)

```text
CO₂ (кг) ≈ вес_вещи (кг) × коэффициент_категории

Мебель         → 0.27
Техника        → 0.50
Стройматериалы → 0.15
Другое         → 0.33
```

## ⚠️ Известные ограничения

| Ограничение | Причина | План |
